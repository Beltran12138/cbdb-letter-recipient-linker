# 消歧器预注册（2026-10-04，写于第一次运行之前）

## 任务
输入：一封信的写信人 ID + 标题；输出：收信人 CBDB ID + 置信度。金标 = CBDB `ASSOC_DATA` 代码 429/431/433/435 的 `c_assoc_id`（14,958 条）。

## 数据划分（写死）
- **按写信人划分**：`c_personid % 5 == 0` → 测试集，其余 → 训练集。同一写信人的信不跨集。
- 阈值、超参只在训练集上用交叉验证（按写信人分组）选，测试集只跑一次报数。

## 防泄漏规则
- 所有特征**不得使用书信关系代码 429–436**（金标本身在这些代码里）。
- 候选人「热门度」特征只用非书信关系计数。
- 已知无法排除的偏差：部分别名可能由这批书信识别时新增（对候选生成有利）；金标只含已识别书信（选择偏差）。结果报告必须附这两条。

## 指标（测试集）
1. Top-1 准确率，分母 = 全部测试书信（无候选算错）
2. 在「多候选且含金标」子集上的 Top-1 准确率
3. 精度-覆盖率：用训练集选出「精度 ≥ 90%」的置信度阈值，报测试集上的实际精度和覆盖率
- 对照：朴素基线 v2（仅在唯一候选时作答）

## 判据（写死）
- **有效**：测试集在实际精度 ≥ 90% 时，覆盖率显著高于基线 v2 的覆盖率（基线 v2 全量上为唯一候选 38%、其中精度约 87%）
- **停止**：多候选子集 Top-1 < 60%，或高置信段测试实际错误率 > 10%
